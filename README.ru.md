# Бюджет города Еревана: документы мэрии в DuckDB

[English](README.md) | [Հայերեն](README.hy.md) | **Русский**

Сбор, нормализация и документирование данных о планировании и исполнении **бюджета города Еревана**, которые
мэрия Еревана публикует в разделе «Финансы» («Ֆինանսներ») своего сайта: <https://www.yerevan.am/hy/finance/>.

Раздел есть только на армянском языке и состоит из файлов (PDF, архивы RAR/ZIP, XLS, DOC), на которые ссылаются
главная страница и архивные страницы 2018–2025 годов. Конвейер собирает **все** эти документы:

* **бюджеты города** 2018–2026 (решения Совета старейшин с приложениями: доходы, расходы по функциональной и
  экономической классификации, дефицит и его финансирование, детальное распределение по программам и
  экономическим статьям для города и каждого из 12 районов), проекты и изменения;
* **отчёты об исполнении** 2017–2026 (форма Հ-9, квартальные и годовые: утверждённый план, уточнённый план, факт);
* **меры по обеспечению исполнения бюджета** 2018–2026 (поквартальная разбивка плана);
* **среднесрочные программы расходов** 2023–2025 … 2027–2029 (прогнозы на три года);
* **бюджетные послания мэра** с таблицами **программного бюджета** (программы, мероприятия, показатели
  результативности) на 2025–2026; гражданские бюджеты, штатные расписания и прочие документы;
* каталог **финансовых документов муниципальных учреждений и компаний** (422 архива, ≈10,6 ГБ; скачиваются по
  запросу, не разбираются).

Результат — база DuckDB `data/yerevan_budget.duckdb`: ≈530 000 сумм в «длинной» таблице фактов со смыслом каждого
столбца (сценарий, год, период, часть бюджета), программный бюджет, классификаторы с **названиями на армянском и
восьми языках перевода** (английский, русский, французский, испанский, португальский, немецкий, арабский,
персидский), полный текст каждой страницы и каждая ячейка таблиц источника, проверки качества и документация на трёх
языках.

## Готовые данные: релизы

База и сырые данные не хранятся в git. Каждый сбор публикуется как **релиз** репозитория
([Releases](https://github.com/opendataam/arm-yerevan-budget/releases)) с тегом `data-ГГГГ-ММ-ДД` — дата сбора; тег
указывает на коммит кода, которым собрана база.

| файл релиза | содержание |
|---|---|
| `yerevan_budget.duckdb.xz` | база DuckDB |
| `yerevan_budget-parquet.zip` | все таблицы и представления в Parquet + словарь данных |
| `yerevan_budget-raw.tar.xz` | сырые данные: страницы сайта, документы, распакованные архивы (`raw/`), извлечённые текст и таблицы (`interim/`), манифесты (`catalog/`) |
| `SHA256SUMS` | контрольные суммы |

```bash
make install
make download            # последний релиз: база -> data/yerevan_budget.duckdb (с проверкой SHA256)
```

Другие варианты: `make download-parquet`, `make download-raw` (затем `make build` пересобирает базу, не обращаясь к
сайту), конкретный снимок — `make download TAG=data-2026-11-06`.

## Быстрый старт: собрать всё самому

```bash
make install   # создаёт .venv и устанавливает пакет (через uv, если есть; Python ≥ 3.10)
make all       # catalog → fetch → extract → build → docs  (≈10 минут, в основном скачивание)
```

Нужны `unrar` (архивы RAR) и `7zz`/`7z` или `bsdtar` (ZIP); файлы `.doc` читаются через `textutil` (macOS) или
`soffice`. По шагам (в активированном окружении: `source .venv/bin/activate`):

```bash
python -m yerevan_budget catalog   # страницы раздела «Финансы» -> data/catalog/{pages,documents}.json
python -m yerevan_budget fetch     # документы -> data/raw/files, распакованные архивы -> data/raw/extracted
python -m yerevan_budget extract   # текст и таблицы каждого файла -> data/interim (кэш)
python -m yerevan_budget build     # -> data/yerevan_budget.duckdb
python -m yerevan_budget docs      # -> docs/data_dictionary.md, docs/{en,hy,ru}/inventory.md
python -m yerevan_budget fetch --institutions   # по желанию: ≈10 ГБ архивов учреждений
```

Пример запроса:

```bash
duckdb -readonly data/yerevan_budget.duckdb -c "
  SELECT fiscal_year, round(revenue_actual_kamd / 1e6, 1) AS revenue_bn_amd,
         round(expenditure_actual_kamd / 1e6, 1) AS expenditure_bn_amd
  FROM v_summary ORDER BY fiscal_year"
```

## Основные таблицы

| таблица / представление | содержание |
|---|---|
| `v_execution`, `v_execution_annual` | отчёты об исполнении: утверждённый / уточнённый план и факт по строкам, частям бюджета и периодам |
| `v_budget_approved` | бюджет, утверждённый Советом: доходы, расходы, дефицит, финансирование |
| `v_budget_program` | детальное распределение: функц. класс × программа × экон. статья, город и районы |
| `v_program_budget` | программный бюджет (программы и мероприятия с кодами) |
| `v_mtef` | среднесрочные прогнозы |
| `v_summary` | итоги по годам |
| `fact_budget_line` | все суммы стандартных форм («длинная» форма) |
| `fact_program_budget`, `fact_program_indicator` | распределение программного бюджета и показатели результативности |
| `dim_functional`, `dim_economic`, `dim_line`, `dim_program`, `dim_measure`, `dim_district`, `dim_label` | классификаторы и названия на hy и каждом языке перевода (`*_en` … `*_fa`) |
| `meta_document`, `meta_file` | документы и файлы с происхождением |
| `raw_page_text`, `raw_table_cell`, `stg_table_row` | текст, ячейки и строки таблиц источника без потерь |

## Оговорки

* Суммы в тысячах драмов, как в документах (`*_kamd`). Данные исполнения — нарастающим итогом с 1 января.
* Итоги и подытоги хранятся вместе с детальными строками — выбирайте один уровень перед суммированием.
* Один год и период могут покрывать несколько документов; представления используют основной
  (`meta_document.is_primary`).
* Административная и фондовая части включают внутренний перевод из резервного фонда, поэтому для немногих строк
  всего ≠ адм. + фонд. (см. [data_quality.md](docs/ru/data_quality.md)).
