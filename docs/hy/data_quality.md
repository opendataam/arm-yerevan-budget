# Տվյալների որակ

[English](../en/data_quality.md) | **Հայերեն** | [Русский](../ru/data_quality.md)

Կառուցումը կատարում է [`sql/qc.sql`](../../sql/qc.sql)-ի ստուգումները և արդյունքները պահում `qc_summary`-ում և
`qc_*` աղյուսակներում.

```sql
SELECT * FROM qc_summary ORDER BY check_name;
```

| ստուգում | ինչ է ստուգում | սպասելի արդյունք |
|---|---|---|
| `revenue_total_equals_parts` | եկամուտների ընդամենը (տող 1000) = հարկեր (1100) + դրամաշնորհներ (1200) + այլ եկամուտներ (1300)՝ յուրաքանչյուր աղյուսակի գումարների յուրաքանչյուր սյան համար | OK. անհամապատասխանությունները ցույց են տալիս արտահանման ժամանակ կորած տողեր (`qc_revenue_total`) |
| `functional_total_equals_sections` | ծախսերի ընդամենը (տող 2000) = գործառական բաժինների գումարը | OK (`qc_functional_total`) |
| `functional_equals_economic` | ընդամենը՝ ըստ գործառական (2000) և տնտեսագիտական (4000) դասակարգման, հավասար են | OK (`qc_functional_vs_economic`) |
| `total_equals_admin_plus_fund` | ընդամենը = վարչական մաս + ֆոնդային մաս՝ յուրաքանչյուր տողում | INFO. ըստ կառուցվածքի տարբերվում է վարչական մասի պահուստային ֆոնդից ֆոնդային մաս փոխանցման տողերի համար (տողեր 1390–1393, 3110–3112, 4050, 4770–4772 և դրանք ներառող ընդամենները). փոխանցումը հաշվվում է երկու մասում էլ (`qc_parts`) |
| `program_city_equals_units` | բյուջեի 6-րդ հավելվածի ընդամենը (քաղաք) = 7-րդ հավելվածի աղյուսակների գումարը (քաղաքապետարան + 12 վարչական շրջան) | OK (`qc_program_districts`) |
| `report_approved_equals_budget` | տարեկան հաշվետվության «հաստատված պլանը» = բյուջեի որոշումը՝ 1000, 1100, 1200, 1300, 4000 տողերի համար | OK (`qc_report_vs_budget`) |
| `documents_with_facts` | յուրաքանչյուր բյուջե, հաշվետվություն, ՄԺԾԾ և կատարումն ապահովող միջոցառումների փաստաթուղթ տվել է փաստեր | 2023–2025 թվականների տարեկան տեղեկանք-հիմնավորումները ձևերի աղյուսակներ չունեն (դրանց Հ-9 ձևն առանձին փաստաթուղթ է) |
| `files_extracted` | յուրաքանչյուր ֆայլ կարդացվել է | OK |
| `tables_with_unknown_layout` | թվերով աղյուսակներ՝ առանց սյուների համարների տողի | INFO. բյուջետային ուղերձներ, տեղեկանք-հիմնավորումներ, հաստիքացուցակներ, կատարման միջոցառումների մասեր. դրանց բջիջները `raw_table_cell`-ում են |
| `translations_complete` | յուրաքանչյուր անվանում ունի անգլերեն և ռուսերեն թարգմանություն | տե՛ս [translations.md](translations.md) |

`qc_coverage`-ը թվարկում է հիմնական փաստաթղթերը՝ ըստ տեսակների և տարիների, և յուրաքանչյուրից ստացված գումարների
քանակը։

## Աղբյուրների և մշակման հայտնի խնդիրներ

* **Ինտերակտիվ բյուջեն** <http://budget.yerevan.am/>, որին հղում է անում բաժինը, հավաքագրման ընթացքում չէր
  պատասխանում և տվյալներում ներառված չէ։
* **2020 թվականի տարեկան հաշվետվություն։** Հրապարակված է միայն տեղեկանք-հիմնավորումը. այնտեղ կան ձևի ծախսերի
  աղյուսակները, բայց եկամուտները չկան, ուստի `v_summary`-ում 2020 թվականի եկամուտներ չկան։
* **2026**. տարեկան հաշվետվությունը դեռ հրապարակված չէ (տվյալներն ավարտվում են 2026 թվականի հունվար–սեպտեմբերով)։
* **Էջի ընդմիջումներում կորած տողեր։** Մի քանի PDF հաշվետվություններում էջի ներքևում սկսվող տողը կտրվում է
  աղյուսակների որոնման ժամանակ (օրինակ՝ 1200 «պաշտոնական դրամաշնորհներ» տողը 2026 թվականի հունվար–հունիսի և
  հունվար–սեպտեմբերի հաշվետվություններում, 1300 տողը 2022 թվականի հունվար–հունիսի հաշվետվությունում)։ QC
  աղյուսակները ցույց են տալիս տուժած սյուները. արժեքները կարելի է կարդալ `raw_page_text`-ից։
* **Նկարներով անվանումներ** 2025–2027 թվականների միջնաժամկետ ծրագրի հավելվածներում. տողերն ունեն կոդեր և
  գումարներ, բայց չունեն անվանումներ (`label_hy` NULL). դիտակները ցույց են տալիս տողի կոդի անվանումը։
* **Կատարումն ապահովող միջոցառումներ, 2-րդ և 10-րդ հավելվածներ**. սյուների համարների տողը կոտրված է տեքստային
  շերտում. այդ աղյուսակների մեծ մասը չի մեկնաբանվում (միայն `raw_table_cell`)։
* **2018 թվականի կատարումն ապահովող միջոցառումներ** (`f6053241d4`)՝ վատ տեքստային շերտով սկան. մշակված է
  աղյուսակների միայն մի մասը։
* **Աղավաղված անվանումներ։** Մի քանի տողի վրա տարածվող անվանումները հին PDF-ներում (2017–2019) երբեմն կտրվում են
  կամ կպչում հաջորդ տողին. կոդերն ու գումարները չեն տուժում, իսկ դիտակները վերցնում են կոդի անվանումը, եթե
  աղավաղված անվանումը թարգմանություն չունի։
* **Կլորացում։** Փաստաթղթերը կլորացնում են մինչև 0,1 հազ. դրամ. գումարները համեմատվում են 1 հազ. դրամ թույլատրելի
  շեղմամբ։
* **Հին տառատեսակներ։** 8-բիթանոց հայկական տառատեսակներից փոխակերպումը ճշգրիտ է տառերի համար. այդ տառատեսակների
  մի քանի հազվադեպ կետադրական նշաններ կարող են անճշգրիտ փոխակերպվել։
* **Կազմակերպությունների փաստաթղթերը** (≈10,6 ԳԲ) միայն ցուցակագրված են։
