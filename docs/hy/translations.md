# Անվանումներ ինը լեզվով

[English](../en/translations.md) | **Հայերեն** | [Русский](../ru/translations.md)

Փաստաթղթերը հրապարակվում են միայն հայերեն։ Բազան պահում է հայերեն անվանումներն այնպես, ինչպես տպված են, և
ավելացնում է դրանց թարգմանությունները git-ում պահվող բառարաններից։

## Լեզուներ

| կոդ | լեզու | ինչու |
|---|---|---|
| `hy` | հայերեն | աղբյուրը. հեղինակավոր տեքստ |
| `en` | անգլերեն | տվյալների միջազգային լեզու |
| `ru` | ռուսերեն | լայնորեն օգտագործվում է Հայաստանում. սփյուռքի ամենամեծ համայնքը (Ռուսաստան) |
| `fr` | ֆրանսերեն | Ֆրանսիա, Բելգիա, Քվեբեկ, Լիբանան |
| `es` | իսպաներեն | Արգենտինա, Ուրուգվայ |
| `pt` | պորտուգալերեն (Բրազիլիա) | Բրազիլիա |
| `de` | գերմաներեն | Գերմանիա |
| `ar` | արաբերեն (գրական) | Լիբանան, Սիրիա, Եգիպտոս, Իրաք, Պարսից ծոցի երկրներ |
| `fa` | պարսկերեն | Իրան |

Ցանկը `LANGS`-ն է `src/yerevan_budget/config.py`-ում։ Հայերեն անվանման յուրաքանչյուր `<name>_hy` սյուն ունի
`<name>_<lang>` սյուն յուրաքանչյուր լեզվի համար. `label_en` … `label_fa`, `name_en` … `name_fa`,
`title_en` … `title_fa`։

## Բառարաններ

`data/translations/<context>.csv`, UTF-8 CSV՝ `hy,en,ru,fr,es,pt,de,ar,fa` սյուներով.

| համատեքստ | բովանդակություն |
|---|---|
| `revenue` | եկամուտների տողեր. հարկեր, տեղական տուրքեր և վճարներ, պետական տուրքեր, դրամաշնորհներ, այլ եկամուտներ |
| `functional` | գործառական դասակարգում. բաժիններ, խմբեր, դասեր |
| `economic` | ծախսերի տնտեսագիտական դասակարգում, տնտեսագիտական բաժնի տողեր |
| `financing` | հավելուրդ / դեֆիցիտ և դրա ֆինանսավորում |
| `program` | ծրագրեր, միջոցառումներ և մանրամասն աղյուսակների ու ծրագրային բյուջեի այլ տողեր |
| `labels` | փաստաթղթերի վերնագրեր, կազմակերպությունների էջերի վերնագրեր, այլ մակագրություններ |
| `reference` | կոդում սահմանված տեղեկատուների անվանումներ (փաստաթղթերի տեսակներ, ժամանակահատվածներ, ձևերի բաժիններ, սցենարներ, բյուջեի մասեր, վարչական շրջաններ). անգլերենը և ռուսերենը վերցվում են կոդից, մյուս լեզուները՝ այս ֆայլից |

Պայմանավորվածությունները (տերմիններ, ոճ, հատուկ անունների տառադարձություն)՝
[GLOSSARY.md](../../data/translations/GLOSSARY.md)-ում։

## Ինչպես են համադրվում անվանումները

* Անվանման բանալին նրա հայերեն տեքստն է՝ կրճատված մինչև տառեր և թվեր (`norm_key`). բացատները, կետադրությունը,
  մեծատառ/փոքրատառը, `եւ` / `և` նշանակություն չունեն։
* Սկզբի համարակալումը (`1.1`, `ա)`, `Ա.`, `-`) որոնումից առաջ անջատվում է և վերադարձվում թարգմանության սկիզբ.
  բանաձևերը (`(տող 1110 + տող 1120)`) և «այդ թվում», «որից» բառերը հեռացվում են փաստերի անվանումներից։
* Անվանումը նախ որոնվում է իր համատեքստում, ապա՝ ցանկացածում։
* Եթե անվանումը թարգմանություն չունի, դիտակները վերցնում են նրա կոդի անվանումը. գործառական դասի (`dim_functional`),
  հոդվածի (`dim_economic`) կամ ձևի տողի (`dim_line`)։

Արդյունքը՝ `dim_label`-ում (տողի յուրաքանչյուր եզակի անվանում), `dim_functional`, `dim_economic`, `dim_line`,
`dim_program`, `dim_measure`, `dim_district` և մյուս տեղեկատուներում, `meta_document.title_<lang>`-ում և
դիտակների `*_<lang>` սյուներում։

## Մեթոդ

* Պետական բյուջեի հետ ընդհանուր գործառական և տնտեսագիտական դասակարգման անվանումները վերցված են հարակից
  [arm-budget](https://github.com/opendataam/arm-budget) նախագծի բառարաններից։
* Մնացած անգլերեն և ռուսերեն անվանումները թարգմանվել են LLM-ի (Claude) միջոցով՝ ըստ բառարանի, խմբաքանակներով՝
  ըստ համատեքստերի, և ստուգվել են տերմինների միատեսակության համար. հեղինակավոր է մնում հայերեն տեքստը։
* Ֆրանսերենը, իսպաներենը, պորտուգալերենը, գերմաներենը, արաբերենը և պարսկերենը թարգմանվել են LLM-ի (Claude)
  միջոցով՝ անգլերենից և ռուսերենից միասին (նույն հայերեն բնագրի երկու անկախ թարգմանություն). յուրաքանչյուր լեզվի
  համար նախ ամրագրվել է հիմնական տերմինների բառարան։ Դրանք դեռ չեն ստուգվել մայրենի լեզվով խոսողների կողմից.
  ուղղումները ողջունելի են։
* Երկար նկարագրությունները (ծրագրերի նպատակներն ու արդյունքները, միջոցառումների նկարագրությունները, արդյունքային
  ցուցանիշները) պահվում են միայն հայերեն։

## Նոր անվանումների թարգմանում

Նոր փաստաթղթի հրապարակումից հետո.

```bash
python -m yerevan_budget build          # առանց թարգմանության անվանումներ -> qc_missing_translation
python -m yerevan_budget translations   # -> data/translations/pending/<context>.csv (հայտնի լեզուները լրացված, պակասողները՝ դատարկ)
# լրացնել դատարկ սյուները (ձեռքով կամ մեքենայական թարգմանությամբ՝ ստուգմամբ)
python -m yerevan_budget translations --merge
python -m yerevan_budget build
```

`--merge`-ը վերցնում է յուրաքանչյուր լրացված բջիջ. դատարկ լեզվով տողերը մնում են `pending/`-ում։
`SELECT * FROM qc_summary WHERE check_name = 'translations_complete'`-ը ցույց է տալիս, թե քանի անվանում է մնացել։

## Ինչպես ավելացնել լեզու

1. Ավելացնել կոդը `LANGS`-ում և անվանումը `LANG_NAMES`-ում (`src/yerevan_budget/config.py`). կառուցումը
   կստեղծի `*_<կոդ>` սյուները բոլոր աղյուսակներում և դիտակներում (`sql/*.sql`-ը կրկնում է `{lang}`-ով տողերը
   յուրաքանչյուր լեզվի համար)։
2. Ավելացնել սյունը `data/translations/*.csv`-ում և լրացնել այն (`python -m yerevan_budget translations`-ը
   անվանումները դուրս կգրի `pending/`. բոլոր անվանումներին պակասում է նոր լեզուն)։
3. Ավելացնել լեզվի տերմինները [GLOSSARY.md](../../data/translations/GLOSSARY.md)-ում, վերակառուցել բազան և
   ստուգել `translations_complete`-ը։
