# Սպասարկում

[English](../en/maintenance.md) | **Հայերեն** | [Русский](../ru/maintenance.md)

## Պարբերական թարմացում

Նոր մեքենայի վրա նախ վերականգնեք վերջին պատկերի չմշակված տվյալները, որպեսզի ոչինչ նորից չներբեռնվի և չարտահանվի.

```bash
make install download-raw
```

Այնուհետև.

```bash
make catalog fetch extract build docs test
git add -A && git commit -m "data: update to $(date +%F)" && git push
make release            # նոր data-<հավաքագրման ամսաթիվ> թողարկում՝ բազայով, Parquet-ով և չմշակված տվյալներով
```

* `catalog`-ը նորից շրջանցում է «Ֆինանսներ» բաժնի էջերը։ Նոր փաստաթղթերն ավտոմատ ավելացվում և դասակարգվում են ըստ
  վերնագրերի. `data/catalog/documents.json`-ի փոփոխությունները երևում են `git diff`-ում՝ հարմար միջոց տեսնելու, թե
  ինչ է հրապարակվել։
* `fetch`-ը ներբեռնում է միայն բացակայող փաստաթղթերը (`--force`՝ բոլորը նորից) և բացում արխիվները
  `data/raw/extracted/<doc_id>/`-ում. ֆայլերի և արխիվների տարրերի չափերն ու SHA-256-ը պահվում են կատալոգում։
* `extract`-ը կարդում է նոր ֆայլերը (PDF-ի տեքստ և աղյուսակներ, էլեկտրոնային աղյուսակներ, Word) `data/interim/`
  քեշում (նույնական ֆայլերը կարդացվում են մեկ անգամ. ամբողջը՝ մոտ 3 րոպե)։
* `build`-ը նորից ստեղծում է ամբողջ բազան (մոտ մեկ րոպե)։ Ստուգեք `SELECT * FROM qc_summary`-ը (տե՛ս
  [data_quality.md](data_quality.md))։
* Նոր անվանումներ → [translations.md](translations.md) (`make translations`, լրացնել, `make translations-merge`,
  `make build`)։
* `release`-ը պահանջում է մաքուր աշխատանքային ծառ, ուղարկված `HEAD` և `gh`՝ `opendataam/arm-yerevan-budget`-ում
  գրելու իրավունքով. պիտակը՝ `data-<շրջանցման ամսաթիվ>`։

Եռամսյակային հաշվետվությունները հրապարակվում են եռամսյակից մոտ 1–2 ամիս հետո, հաջորդ տարվա բյուջեն՝ դեկտեմբերին,
միջնաժամկետ ծրագիրը՝ սեպտեմբերին. ամսական թարմացումը բավարար է։

## Ինչ անել, եթե…

**Փաստաթղթին տրված է սխալ տեսակ, տարի կամ ժամանակահատված։** Կանոնները
[`classify.py`](../../src/yerevan_budget/classify.py)-ում են. ավելացրեք կանոն կամ գրառում `OVERRIDES`-ում
(բանալին՝ `doc_id`) և ավելացրեք վերնագիրը `tests/test_parsers.py`-ում։

**Աղյուսակի նոր դասավորությունը չի ճանաչվում** (`tables_with_unknown_layout`, առանց փաստերի փաստաթուղթ
`qc_coverage`-ում)։ Նայեք ֆայլի տողերը `raw_table_cell` / `stg_table_row`-ում։ Բյուջետային աղյուսակները ճանաչվում են
սյուների համարների տողով ([`parsers/budget_tables.py`](../../src/yerevan_budget/parsers/budget_tables.py)).
գումարների սյուների իմաստը որոշվում է վերնագրի տեքստով և փաստաթղթի տեսակով
([`parsers/semantics.py`](../../src/yerevan_budget/parsers/semantics.py), `FACT_LAYOUTS`՝ `build.py`-ում)։

**Տեքստը ստացվում է `Ð³í»Éí³Í` կամ գլիֆների համարների տեսքով։** Հին տառատեսակները փոխակերպում է
[`parsers/armscii.py`](../../src/yerevan_budget/parsers/armscii.py)-ը. Unicode քարտեզ չունեցող տառատեսակները
վերականգնվում են ներդրված տառատեսակից `extract.py`-ում (`_glyph_maps`)։ Արտահանումը փոխելուց հետո մեծացրեք
`extract.VERSION`-ը և գործարկեք `make extract build`։

**Ստուգիչ գումարը չի համընկնում։** Գտեք փաստաթուղթը և սյունը `qc_*` աղյուսակում, ապա տողերը `stg_table_row`-ում
(`file_id`, `seq`) և էջը `raw_page_text`-ում։ Տիպիկ պատճառներ. էջի ընդմիջման վրա կտրված տող, երկու տող մեկ բջջում,
տողի նոր կոդ։

**Կայքը փոխել է էջերը։** Էջերի ցուցակը `config.PAGES`-ն է. հղումները կարդացվում են էջի բովանդակության բլոկից
[`parsers/pages.py`](../../src/yerevan_budget/parsers/pages.py)-ի միջոցով։

## Կոդի կառուցվածք

| մոդուլ | դեր |
|---|---|
| `config.py` | ուղիներ, բաժնի էջեր, HTTP կարգավորումներ |
| `http.py` | HTTP հաճախորդ. դադարներ, կրկնություններ, հոսքային ներբեռնում |
| `catalog.py` | քայլ 1. էջերի շրջանցում → `data/catalog/pages.json`, `documents.json` |
| `classify.py` | փաստաթղթի տեսակը / տարին / ժամանակահատվածը՝ ըստ վերնագրի |
| `fetch.py` | քայլ 2. ներբեռնում, արխիվների բացում, հեշեր |
| `extract.py` | քայլ 3. յուրաքանչյուր ֆայլի տեքստ և աղյուսակներ → `data/interim` |
| `build.py` | քայլ 4. DuckDB-ի կառուցում (`sql/schema.sql`, `sql/dims.sql`, `sql/views.sql`, `sql/qc.sql`) |
| `parsers/armscii.py` | հայկական հին տառատեսակներ → Unicode |
| `parsers/pages.py` | էջերի հղումներ և վերնագրեր |
| `parsers/budget_tables.py` | սյուների համարների տողով աղյուսակներ → տրամաբանական տողեր |
| `parsers/semantics.py` | բաժիններ, տողերի տեսակներ, գումարների սյուների իմաստը |
| `parsers/program_tables.py` | ծրագրային բյուջեի աղյուսակներ (ԾԲ) |
| `parsers/common.py` | արժեքներ, կոդեր, անվանումներ |
| `translations.py` | hy → en / ru / fr / es / pt / de / ar / fa բառարաններ |
| `reference.py` | Երևանի վարչական շրջաններ |
| `docs.py`, `release.py` | ավտոմատ փաստաթղթավորում, տվյալների պատկերներ GitHub թողարկումներում |
| `cli.py`, `__main__.py` | հրամանային տող |
