# Названия на трёх языках

[English](../en/translations.md) | [Հայերեն](../hy/translations.md) | **Русский**

Документы публикуются только на армянском. База хранит армянские названия как напечатано и добавляет английские и
русские названия из словарей переводов, которые хранятся в git.

## Словари

`data/translations/<context>.csv`, UTF-8 CSV со столбцами `hy,en,ru`:

| контекст | содержание |
|---|---|
| `revenue` | строки доходов: налоги, местные пошлины и сборы, госпошлины, гранты, прочие доходы |
| `functional` | функциональная классификация: разделы, группы, классы |
| `economic` | экономическая классификация расходов, строки экономического раздела |
| `financing` | профицит / дефицит и его финансирование |
| `program` | программы, мероприятия и прочие строки детальных таблиц и программного бюджета |
| `labels` | названия документов, заголовки страниц учреждений, прочие подписи |

Соглашения (термины, стиль, транслитерация имён собственных) — в
[GLOSSARY.md](../../data/translations/GLOSSARY.md).

## Как сопоставляются названия

* Ключ названия — армянский текст, сокращённый до букв и цифр (`norm_key`): пробелы, пунктуация, регистр,
  `եւ` / `և` не важны.
* Нумерация в начале (`1.1`, `ա)`, `Ա.`, `-`) отделяется перед поиском и возвращается перед переводом; формулы
  (`(տող 1110 + տող 1120)`) и слова «в том числе» (`այդ թվում`, `որից`) удаляются из названий в фактах.
* Название ищется сначала в своём контексте, затем в любом.
* Если у названия нет перевода, представления берут название его кода: функционального класса (`dim_functional`),
  статьи (`dim_economic`) или строки формы (`dim_line`).

Результат — в `dim_label` (каждое уникальное название строки), `dim_functional`, `dim_economic`, `dim_line`,
`dim_program`, `dim_measure`, `meta_document.title_en / title_ru` и в столбцах `*_en`, `*_ru` представлений.

## Метод

* Названия функциональной и экономической классификации, общие с государственным бюджетом, взяты из словарей
  соседнего проекта [arm-budget](https://github.com/opendataam/arm-budget).
* Остальные названия переведены с помощью LLM (Claude) по глоссарию, пакетами по контекстам, и проверены на
  единообразие терминов; авторитетным остаётся армянский текст.
* Длинные описания (цели и результаты программ, описания мероприятий, показатели результативности) хранятся только
  на армянском.

## Перевод новых названий

После публикации нового документа:

```bash
python -m yerevan_budget build          # названия без перевода -> qc_missing_translation
python -m yerevan_budget translations   # -> data/translations/pending/<context>.csv (hy заполнен, en/ru пусты)
# заполнить en и ru (вручную или машинным переводом с проверкой)
python -m yerevan_budget translations --merge
python -m yerevan_budget build
```

`SELECT * FROM qc_summary WHERE check_name = 'translations_complete'` показывает, сколько названий осталось.
