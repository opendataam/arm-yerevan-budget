# Названия на девяти языках

[English](../en/translations.md) | [Հայերեն](../hy/translations.md) | **Русский**

Документы публикуются только на армянском. База хранит армянские названия как напечатано и добавляет их переводы
из словарей, которые хранятся в git.

## Языки

| код | язык | почему |
|---|---|---|
| `hy` | армянский | источник; авторитетный текст |
| `en` | английский | международный язык данных |
| `ru` | русский | широко используется в Армении; крупнейшая община диаспоры (Россия) |
| `fr` | французский | Франция, Бельгия, Квебек, Ливан |
| `es` | испанский | Аргентина, Уругвай |
| `pt` | португальский (Бразилия) | Бразилия |
| `de` | немецкий | Германия |
| `ar` | арабский (литературный) | Ливан, Сирия, Египет, Ирак, страны Залива |
| `fa` | персидский (фарси) | Иран |

Список — `LANGS` в `src/yerevan_budget/config.py`. У каждого столбца с армянским названием `<name>_hy` есть столбец
`<name>_<lang>` для каждого языка: `label_en` … `label_fa`, `name_en` … `name_fa`, `title_en` … `title_fa`.

## Словари

`data/translations/<context>.csv`, UTF-8 CSV со столбцами `hy,en,ru,fr,es,pt,de,ar,fa`:

| контекст | содержание |
|---|---|
| `revenue` | строки доходов: налоги, местные пошлины и сборы, госпошлины, гранты, прочие доходы |
| `functional` | функциональная классификация: разделы, группы, классы |
| `economic` | экономическая классификация расходов, строки экономического раздела |
| `financing` | профицит / дефицит и его финансирование |
| `program` | программы, мероприятия и прочие строки детальных таблиц и программного бюджета |
| `labels` | названия документов, заголовки страниц учреждений, прочие подписи |
| `reference` | названия справочников, заданных в коде (типы документов, периоды, разделы форм, сценарии, части бюджета, районы): английский и русский берутся из кода, остальные языки — из этого файла |

Соглашения (термины, стиль, транслитерация имён собственных) — в
[GLOSSARY.md](../../data/translations/GLOSSARY.md).

## Как сопоставляются названия

* Ключ названия — армянский текст, сокращённый до букв и цифр (`norm_key`): пробелы, пунктуация, регистр,
  `եւ` / `և` не важны.
* Нумерация в начале (`1.1`, `ա)`, `Ա.`, `-`) отделяется перед поиском и возвращается перед переводом; формулы
  (`(տող 1110 + տող 1120)`) и слова «в том числе» (`այդ թվում`, `որից`) удаляются из названий в фактах.
* Название ищется сначала в своём контексте, затем в любом.
* Если у названия нет перевода, представления берут название его кода: функционального класса (`dim_functional`),
  статьи (`dim_economic`) или строки формы (`dim_line`).

Результат — в `dim_label` (каждое уникальное название строки), `dim_functional`, `dim_economic`, `dim_line`,
`dim_program`, `dim_measure`, `dim_district` и других справочниках, `meta_document.title_<lang>` и в столбцах
`*_<lang>` представлений.

## Метод

* Названия функциональной и экономической классификации, общие с государственным бюджетом, взяты из словарей
  соседнего проекта [arm-budget](https://github.com/opendataam/arm-budget).
* Остальные английские и русские названия переведены с помощью LLM (Claude) по глоссарию, пакетами по контекстам, и
  проверены на единообразие терминов; авторитетным остаётся армянский текст.
* Французский, испанский, португальский, немецкий, арабский и персидский переведены с помощью LLM (Claude) с
  английского и русского вместе (два независимых перевода одного армянского оригинала); для каждого языка сначала
  зафиксирован глоссарий ключевых терминов. Носители языка их ещё не проверяли: исправления приветствуются.
* Длинные описания (цели и результаты программ, описания мероприятий, показатели результативности) хранятся только
  на армянском.

## Перевод новых названий

После публикации нового документа:

```bash
python -m yerevan_budget build          # названия без перевода -> qc_missing_translation
python -m yerevan_budget translations   # -> data/translations/pending/<context>.csv (известные языки заполнены, недостающие пусты)
# заполнить пустые столбцы (вручную или машинным переводом с проверкой)
python -m yerevan_budget translations --merge
python -m yerevan_budget build
```

`--merge` забирает каждую заполненную ячейку; строки с пустым языком остаются в `pending/`.
`SELECT * FROM qc_summary WHERE check_name = 'translations_complete'` показывает, сколько названий осталось.

## Как добавить язык

1. Добавить код в `LANGS` и название в `LANG_NAMES` в `src/yerevan_budget/config.py`: сборка создаст столбцы
   `*_<код>` во всех таблицах и представлениях (`sql/*.sql` повторяют строки с `{lang}` для каждого языка).
2. Добавить столбец в `data/translations/*.csv` и заполнить его (`python -m yerevan_budget translations` выпишет
   названия в `pending/`: всем названиям не хватает нового языка).
3. Добавить термины языка в [GLOSSARY.md](../../data/translations/GLOSSARY.md), пересобрать базу и проверить
   `translations_complete`.
