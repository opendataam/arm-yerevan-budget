## Сайт

Мэрия Еревана публикует документы бюджета города в разделе «Финансы» («Ֆինանսներ») своего сайта:
<https://www.yerevan.am/hy/finance/>. Раздел существует только на армянском языке: английская и русская версии
страницы (`/en/finance/`, `/ru/finance/`) сообщают «Содержание доступно только на армянском языке».

Раздел состоит из главной страницы и подстраниц, на которые она ссылается:

| страница (`https://www.yerevan.am/hy/<slug>/`) | содержание | группа |
|---|---|---|
| `finance` | документы текущего года (2026) | core |
| `archive-documents-of-2018` … `archive-documents-of-2022`, `finance-archive-documents-of-2023` … `-2025` | архив прошлых лет (один документ может быть на двух страницах) | core |
| `byowje-bolori-hamar` | «Бюджет для всех» — гражданский бюджет | core |
| `finance-docs` | годовые финансовые документы государственных и общинных некоммерческих организаций, подведомственных мэрии (школы, детсады, музыкальные, художественные и спортивные школы, …): сметы, уточнённые сметы, фактическое исполнение, штатные расписания, 2014–2026 | institutions |
| `finance-other-docs` | то же для общинных ЗАО по отраслям (здравоохранение, коммунальное хозяйство, спорт и культура, транспорт, ИТ, градостроительство), 2025–2026 | institutions |
| `interactive-budget` | ссылка на «интерактивный бюджет» <http://budget.yerevan.am/> (во время сбора был недоступен) | link |

Каждый документ — обычная ссылка (`<a href>`) на файл: PDF, архивы RAR / ZIP (внутри PDF, DOC/DOCX, XLS/XLSX),
XLS. Кроме текста ссылки, на сайте нет ни идентификаторов, ни метаданных документов; конвейер классифицирует
документы по заголовкам (см. [documents.md](documents.md)).

* **Основные документы** — 88 различных документов (≈176 МБ, 214 файлов после распаковки архивов), 2017–2027.
  Они скачиваются, распаковываются и разбираются в базу данных.
* **Документы муниципальных учреждений** — 422 RAR-архива, ≈10,6 ГБ. Они перечислены в каталоге и в
  `meta_document` (заголовок группы, год, название, размер по данным сайта) и скачиваются командой
  `python -m yerevan_budget fetch --institutions` (`make fetch-institutions`); они не разбираются: внутри — сканы и
  Excel-сметы сотен отдельных учреждений в разных макетах.

## Форматы и их особенности

* **Устаревшие армянские шрифты.** Большинство приложений и многие отчёты набраны 8-битными шрифтами
  «Arial Armenian» / «Times Armenian» (раскладка ArmSCII-8): текстовый слой PDF и ячейки XLS содержат символы
  Latin-1 (`Ð³í»Éí³Í` вместо `Հավելված`). При извлечении каждый такой фрагмент переводится в Unicode
  ([`parsers/armscii.py`](../../src/yerevan_budget/parsers/armscii.py)); `0xA8` в этих шрифтах — `և`. Unicode и
  старые шрифты смешаны даже на одной странице, поэтому решение принимается для каждого фрагмента / ячейки.
* **Шрифты без таблицы Unicode.** Отчёт за январь–сентябрь 2021 набран шрифтом GHEA Grapalat, встроенным как
  CID-шрифт без таблицы ToUnicode: извлечение текста возвращает номера глифов. Таблица восстанавливается из `cmap`
  встроенной программы шрифта (fontTools).
* **«Жирный» двойной печатью** (каждый символ напечатан дважды) — удаляется `dedupe_chars` pdfplumber.
* **Текст картинками.** В приложениях среднесрочной программы 2025–2027 названия строк — изображения, текстом
  только коды и числа. Строки разбираются, названия берутся по кодам строк.
* **Excel 2003 XML** с расширением `.xls` (MTEF 2024–2026) читается как SpreadsheetML.
* **Дубли.** Один файл иногда опубликован по двум URL (`meta_document.duplicate_of`), один отчёт — в двух
  документах; одинаковые файлы разбираются один раз, а представления используют один основной документ на тип /
  год / период (`meta_document.is_primary`).
* **Единицы.** Все суммы в тысячах драмов (как в документах). Отрицательные суммы печатаются с минусом или в
  скобках; `X` — «не применяется» (NULL), `-` — ноль.
* **Периоды.** Квартальные отчёты — нарастающим итогом с 1 января: `Q1` январь–март, `H1` январь–июнь, `9M`
  январь–сентябрь, `FY` год.

## Бюджетные формы

Все таблицы следуют стандартным формам бюджетов общин (приказ министра финансов, форма Հ-9):

* **доходы** (строки `1000`–`1393`, пятизначные подстроки `11301`…, `13501`… — местные пошлины и сборы) и коды
  статей доходов (`7100` налоги и пошлины, `7131` имущественные налоги на недвижимость, …);
* **расходы по функциональной классификации** (строки `2000`–`3xxx`; коды раздела / группы / класса, например
  `09 1 1` — дошкольное образование);
* **расходы по экономической классификации** (строки `4000`–`6xxx`; статьи `4111` заработная плата, `5113`
  капитальный ремонт зданий, …);
* **профицит / дефицит** (строка `7000` в отчётах, `8000` в решении о бюджете) и **его финансирование**
  (строки `8000`/`8010`–`8xxx`, статьи `9xxx`);
* столбцы **административной части** (текущий бюджет) и **фондовой части** (капитальный бюджет) и их сумма.

Детальные таблицы (приложение 6 к бюджету: функциональный класс × программа × экономическая статья; приложение 7:
то же для мэрии и каждого из 12 административных районов) и таблицы программного бюджета (с 2025, с кодами программ
и мероприятий и показателями результативности) показывают распределение глубже классификации.

Содержание каждого документа — в [documents.md](documents.md), устройство базы — в [database.md](database.md).
