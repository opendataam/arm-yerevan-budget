# Качество данных

[English](../en/data_quality.md) | [Հայերեն](../hy/data_quality.md) | **Русский**

Сборка выполняет проверки из [`sql/qc.sql`](../../sql/qc.sql) и сохраняет результаты в `qc_summary` и таблицах
`qc_*`:

```sql
SELECT * FROM qc_summary ORDER BY check_name;
```

| проверка | что проверяет | ожидаемо |
|---|---|---|
| `revenue_total_equals_parts` | итог доходов (строка 1000) = налоги (1100) + гранты (1200) + прочие доходы (1300) для каждого столбца сумм каждой таблицы | OK; расхождения указывают на строки, потерянные при извлечении (`qc_revenue_total`) |
| `functional_total_equals_sections` | итог расходов (строка 2000) = сумма функциональных разделов | OK (`qc_functional_total`) |
| `functional_equals_economic` | итоги по функциональной (2000) и экономической (4000) классификации равны | OK (`qc_functional_vs_economic`) |
| `total_equals_admin_plus_fund` | всего = административная часть + фондовая часть в каждой строке | INFO: по построению отличается для строк перевода из резервного фонда административной части в фондовую (строки 1390–1393, 3110–3112, 4050, 4770–4772 и итоги, которые их включают) — перевод учитывается в обеих частях (`qc_parts`) |
| `program_city_equals_units` | итог приложения 6 к бюджету (город) = сумма таблиц приложения 7 (мэрия + 12 районов) | OK (`qc_program_districts`) |
| `report_approved_equals_budget` | «утверждённый план» годового отчёта = решение о бюджете по строкам 1000, 1100, 1200, 1300, 4000 | OK (`qc_report_vs_budget`) |
| `documents_with_facts` | каждый бюджет, отчёт, MTEF и документ о мерах исполнения дал факты | у годовых пояснительных записок 2023–2025 нет таблиц форм (их форма Հ-9 — отдельный документ) |
| `files_extracted` | каждый файл прочитан | OK |
| `tables_with_unknown_layout` | таблицы с числами без строки номеров столбцов | INFO: бюджетные послания, пояснительные записки, штатные расписания, части мер исполнения — их ячейки в `raw_table_cell` |
| `translations_complete` | у каждого названия есть перевод на каждый язык (en, ru, fr, es, pt, de, ar, fa) | см. [translations.md](translations.md) |

`qc_coverage` перечисляет основные документы по типам и годам и число сумм из каждого.

## Известные проблемы источников и разбора

* **Интерактивный бюджет** <http://budget.yerevan.am/>, на который ссылается раздел, не отвечал во время сбора и в
  данные не входит.
* **Годовой отчёт за 2020.** Опубликована только пояснительная записка: в ней есть таблицы расходов формы, но нет
  доходов, поэтому в `v_summary` за 2020 нет доходов.
* **2026** — годовой отчёт ещё не опубликован (данные заканчиваются январём–сентябрём 2026).
* **Строки, потерянные на разрывах страниц.** В нескольких PDF-отчётах строка, начинающаяся внизу страницы,
  обрезается при поиске таблиц (например, строка 1200 «официальные гранты» в отчётах за январь–июнь и январь–сентябрь
  2026, строка 1300 в отчёте за январь–июнь 2022). Таблицы QC показывают затронутые столбцы; значения можно прочитать
  в `raw_page_text`.
* **Названия картинками** в приложениях среднесрочной программы 2025–2027: у строк есть коды и суммы, но нет
  названий (`label_hy` NULL); представления показывают название кода строки.
* **Меры исполнения, приложения 2 и 10**: строка номеров столбцов разбита в текстовом слое; большинство этих таблиц
  не интерпретируются (только `raw_table_cell`).
* **Меры исполнения 2018** (`f6053241d4`) — скан с плохим текстовым слоем: разобрана только часть таблиц.
* **Искажённые названия.** Названия, переносящиеся на несколько строк, в старых PDF (2017–2019) иногда обрезаются
  или приклеиваются к следующей строке; коды и суммы при этом не страдают, а представления берут название кода, если
  у искажённого названия нет перевода.
* **Округление.** Документы округляют до 0,1 тыс. драмов; суммы сравниваются с допуском 1 тыс. драмов.
* **Старые шрифты.** Конвертация из 8-битных армянских шрифтов точна для букв; немногие редкие знаки пунктуации этих
  шрифтов могут быть отображены неточно.
* **Документы учреждений** (≈10,6 ГБ) только каталогизированы.
