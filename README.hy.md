# Երևան քաղաքի բյուջե. քաղաքապետարանի փաստաթղթերը DuckDB-ում

[English](README.md) | **Հայերեն** | [Русский](README.ru.md)

Հավաքագրում, նորմալացում և փաստաթղթավորում՝ **Երևան քաղաքի բյուջեի** պլանավորման և կատարման տվյալների, որոնք
Երևանի քաղաքապետարանը հրապարակում է իր կայքի «Ֆինանսներ» բաժնում՝ <https://www.yerevan.am/hy/finance/>։

Բաժինը հասանելի է միայն հայերեն և բաղկացած է ֆայլերից (PDF, RAR/ZIP արխիվներ, XLS, DOC), որոնց հղումները կան
գլխավոր էջում և 2018–2025 թվականների արխիվային էջերում։ Փոխակրիչը (pipeline) հավաքագրում է **բոլոր** այդ
փաստաթղթերը.

* **քաղաքի բյուջեները** 2018–2026 (ավագանու որոշումները՝ հավելվածներով. եկամուտներ, ծախսեր՝ ըստ գործառական և
  տնտեսագիտական դասակարգման, դեֆիցիտ և դրա ֆինանսավորում, ծախսերի մանրամասն բաշխում՝ ըստ ծրագրերի և
  տնտեսագիտական հոդվածների՝ քաղաքի և 12 վարչական շրջաններից յուրաքանչյուրի համար), նախագծեր և փոփոխություններ.
* **կատարման հաշվետվություններ** 2017–2026 (Հ-9 ձև, եռամսյակային և տարեկան. հաստատված պլան, ճշտված պլան, փաստացի).
* **բյուջեի կատարումն ապահովող միջոցառումներ** 2018–2026 (պլանի եռամսյակային բաշխում).
* **միջնաժամկետ ծախսերի ծրագրեր** 2023–2025 … 2027–2029 (եռամյա կանխատեսումներ).
* **քաղաքապետի բյուջետային ուղերձներ**՝ **ծրագրային բյուջեի** աղյուսակներով (ծրագրեր, միջոցառումներ, արդյունքային
  ցուցանիշներ) 2025–2026 թվականների համար, «Բյուջե՝ բոլորի համար» գրքույկներ, հաստիքացուցակներ և այլ փաստաթղթեր.
* **համայնքային կազմակերպությունների և ընկերությունների ֆինանսական փաստաթղթերի** ցուցակ (422 արխիվ, ≈10,6 ԳԲ.
  ներբեռնվում են ըստ պահանջի, չեն մշակվում)։

Արդյունքը DuckDB տվյալների բազա է՝ `data/yerevan_budget.duckdb`. ≈530 000 գումար փաստերի «երկար» աղյուսակում՝
յուրաքանչյուր սյան իմաստով (սցենար, տարի, ժամանակահատված, բյուջեի մաս), ծրագրային բյուջե, դասակարգիչներ՝
**հայերեն և ութ լեզվով թարգմանված անվանումներով** (անգլերեն, ռուսերեն, ֆրանսերեն, իսպաներեն, պորտուգալերեն,
գերմաներեն, արաբերեն, պարսկերեն), աղբյուրի յուրաքանչյուր էջի ամբողջական տեքստը և աղյուսակների յուրաքանչյուր
բջիջը, տվյալների որակի ստուգումներ և փաստաթղթավորում երեք լեզվով։

## Պատրաստի տվյալներ. թողարկումներ (releases)

Տվյալների բազան և չմշակված տվյալները git-ում չեն պահվում։ Յուրաքանչյուր հավաքագրում հրապարակվում է որպես
պահոցի **թողարկում** ([Releases](https://github.com/opendataam/arm-yerevan-budget/releases))՝ `data-ՏՏՏՏ-ԱԱ-ՕՕ`
պիտակով (հավաքագրման ամսաթիվը). պիտակը ցույց է տալիս կոդի այն commit-ը, որով կառուցվել է բազան։

| թողարկման ֆայլ | բովանդակություն |
|---|---|
| `yerevan_budget.duckdb.xz` | DuckDB տվյալների բազա |
| `yerevan_budget-parquet.zip` | բոլոր աղյուսակները և դիտակները Parquet ձևաչափով + տվյալների բառարան |
| `yerevan_budget-raw.tar.xz` | չմշակված տվյալներ. կայքի էջեր, փաստաթղթեր, բացված արխիվներ (`raw/`), արտահանված տեքստ և աղյուսակներ (`interim/`), մանիֆեստներ (`catalog/`) |
| `SHA256SUMS` | ստուգիչ գումարներ |

```bash
make install
make download            # վերջին թողարկումը. բազա -> data/yerevan_budget.duckdb (SHA256 ստուգմամբ)
```

Այլ տարբերակներ. `make download-parquet`, `make download-raw` (այնուհետև `make build`-ը վերակառուցում է բազան՝
առանց կայքին դիմելու), կոնկրետ պատկեր՝ `make download TAG=data-2026-11-06`։

## Արագ մեկնարկ. ամբողջը կառուցել ինքնուրույն

```bash
make install   # ստեղծում է .venv և տեղադրում փաթեթը (uv-ով, եթե կա. Python ≥ 3.10)
make all       # catalog → fetch → extract → build → docs  (≈10 րոպե, հիմնականում ներբեռնում)
```

Անհրաժեշտ են `unrar` (RAR արխիվներ) և `7zz`/`7z` կամ `bsdtar` (ZIP). `.doc` ֆայլերը կարդացվում են `textutil`-ով
(macOS) կամ `soffice`-ով։ Քայլ առ քայլ (ակտիվացված միջավայրում՝ `source .venv/bin/activate`).

```bash
python -m yerevan_budget catalog   # «Ֆինանսներ» բաժնի էջերը -> data/catalog/{pages,documents}.json
python -m yerevan_budget fetch     # փաստաթղթեր -> data/raw/files, բացված արխիվներ -> data/raw/extracted
python -m yerevan_budget extract   # յուրաքանչյուր ֆայլի տեքստ և աղյուսակներ -> data/interim (քեշ)
python -m yerevan_budget build     # -> data/yerevan_budget.duckdb
python -m yerevan_budget docs      # -> docs/data_dictionary.md, docs/{en,hy,ru}/inventory.md
python -m yerevan_budget fetch --institutions   # ըստ ցանկության. կազմակերպությունների ≈10 ԳԲ արխիվները
```

Հարցման օրինակ.

```bash
duckdb -readonly data/yerevan_budget.duckdb -c "
  SELECT fiscal_year, round(revenue_actual_kamd / 1e6, 1) AS revenue_bn_amd,
         round(expenditure_actual_kamd / 1e6, 1) AS expenditure_bn_amd
  FROM v_summary ORDER BY fiscal_year"
```

## Փաստաթղթավորում

Փաստաթղթավորումը հասանելի է անգլերեն ([docs/en](docs/en)), հայերեն ([docs/hy](docs/hy)) և ռուսերեն
([docs/ru](docs/ru))։

| փաստաթուղթ | բովանդակություն |
|---|---|
| [sources.md](docs/hy/sources.md) | կայքի բաժինը, փաստաթղթերի տեսակները, ձևաչափերը և դրանց առանձնահատկությունները, բյուջետային ձևերը |
| [documents.md](docs/hy/documents.md) | յուրաքանչյուր տեսակի փաստաթղթի բովանդակությունը և աղյուսակների ճանաչումը |
| [database.md](docs/hy/database.md) | բազայի նախագծումը. սկզբունքներ, սխեմա (ER), աղյուսակներ, դիտակներ, հարցումների օրինակներ |
| [data_dictionary.md](docs/data_dictionary.md) | բոլոր աղյուսակները և սյուները (ավտոմատ, անգլերեն) |
| [translations.md](docs/hy/translations.md) | անվանումներ ինը լեզվով. լեզուներ, բառարաններ, մեթոդ, նոր անվանումների թարգմանում |
| [data_quality.md](docs/hy/data_quality.md) | որակի ստուգումներ և հայտնի խնդիրներ |
| [inventory.md](docs/hy/inventory.md) | փաստաթղթերի ցուցակ (ավտոմատ) |
| [maintenance.md](docs/hy/maintenance.md) | թարմացում, նոր փաստաթղթեր, կայքի փոփոխություններ, կոդի կառուցվածք |
| [examples.ipynb](docs/examples.ipynb) | Jupyter նոութբուք՝ հարցումների և գծապատկերների օրինակներով (`make lab`, `make notebook`. տեքստը՝ ռուսերեն) |

## Հիմնական աղյուսակները

| աղյուսակ / դիտակ | բովանդակություն |
|---|---|
| `v_execution`, `v_execution_annual` | կատարման հաշվետվություններ. հաստատված / ճշտված պլան և փաստացի՝ ըստ տողերի, բյուջեի մասերի և ժամանակահատվածների |
| `v_budget_approved` | ավագանու հաստատած բյուջե. եկամուտներ, ծախսեր, դեֆիցիտ, ֆինանսավորում |
| `v_budget_program` | մանրամասն բաշխում. գործառական դաս × ծրագիր × տնտեսագիտական հոդված, քաղաք և վարչական շրջաններ |
| `v_program_budget` | ծրագրային բյուջե (ծրագրեր և միջոցառումներ՝ կոդերով) |
| `v_mtef` | միջնաժամկետ կանխատեսումներ |
| `v_summary` | ամփոփ ցուցանիշներ ըստ տարիների |
| `fact_budget_line` | ստանդարտ ձևերի բոլոր գումարները («երկար» ձև) |
| `fact_program_budget`, `fact_program_indicator` | ծրագրային բյուջեի բաշխում և արդյունքային ցուցանիշներ |
| `dim_functional`, `dim_economic`, `dim_line`, `dim_program`, `dim_measure`, `dim_district`, `dim_label` | դասակարգիչներ և անվանումներ hy և թարգմանության յուրաքանչյուր լեզվով (`*_en` … `*_fa`) |
| `meta_document`, `meta_file` | փաստաթղթեր և ֆայլեր՝ ծագմամբ |
| `raw_page_text`, `raw_table_cell`, `stg_table_row` | աղբյուրի տեքստը, բջիջները և աղյուսակների տողերը՝ առանց կորուստների |

## Վերապահումներ

* Գումարները հազար դրամով են, ինչպես փաստաթղթերում (`*_kamd`)։ Կատարման տվյալները աճողական են՝ հունվարի 1-ից։
* Ընդամենը և ենթաընդամենը տողերը պահվում են մանրամասն տողերի հետ միասին. գումարելուց առաջ ընտրեք մեկ մակարդակ։
* Նույն տարին և ժամանակահատվածը կարող են ծածկել մի քանի փաստաթղթեր. դիտակներն օգտագործում են հիմնականը
  (`meta_document.is_primary`)։
* Վարչական և ֆոնդային մասերը ներառում են պահուստային ֆոնդից ներքին փոխանցումը, ուստի որոշ տողերի համար ընդամենը ≠
  վարչական + ֆոնդային (տե՛ս [data_quality.md](docs/hy/data_quality.md))։
